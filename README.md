## 🎯 About Me

<p align="center">

</p>

I architect **end-to-end data platforms** from raw ingestion to dashboard-ready gold layers. My expertise spans:

- 🏗️ **Data Architecture:** Medallion architecture, star/fact-dimension modeling
- 🔄 **Pipeline Engineering:** ETL/ELT, incremental processing, schema evolution
- 📊 **Analytics Engineering:** dbt Core, workflow orchestration, data validation
- 📈 **Business Intelligence:** Power BI, SQL-based reporting, stakeholder dashboards

> **Impact:** Reduced manual reporting effort by **40%** through automated pipelines.
